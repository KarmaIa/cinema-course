Стек технологий
Frontend: React (Vite)
Backend: PHP 8+ (чистый, без фреймворков)
База данных: SQLite (PDO)

База данных не хранится в репозитории, так как она генерируется скриптами инициализации
Инструкция по запуску и настройке БД
Для запуска проекта вам понадобятся установленные Node.js и PHP.

Шаг 1. Настройка базы данных (Backend)
Вся работа с базой данных находится в папке DataBase/.

Создание таблиц:
Откройте терминал в корне проекта (папка cinema-course) и выполните команду:

php DataBase/init_db.php
Этот скрипт создаст файл базы данных cinema.sqlite в корне проекта и создаст все необходимые таблицы (films, halls, sessions, tickets).

Заполнение тестовыми данными:
Чтобы не создавать всё вручную через админку, запустите скрипт заполнения:

php DataBase/seed.php
Этот скрипт добавит в базу несколько тестовых фильмов и залов.

Важно: Если вы хотите полностью очистить базу и начать заново, просто удалите файл cinema.sqlite из корня проекта и повторите Шаг 1 заново.

Шаг 2. Запуск серверной части (PHP API)
Запустите встроенный сервер PHP. Из корневой папки cinema-course выполните:

php -S localhost:8000 -t cinema-server
Сервер будет запущен на порту 8000. Все API-запросы будут доступны по адресу http://localhost:8000/api/....

Шаг 3. Запуск клиентской части (React)
Откройте новый терминал (не закрывая сервер PHP).

Перейдите в папку клиента:
cd cinema-client

Установите зависимости (если делаете это впервые):
npm install

Запустите сервер разработки:
npm run dev

Откройте в браузере ссылку, которую выдаст Vite (обычно http://localhost:5173).


Структура проекта:

```text
cinema-course/
├── cinema-client/       # React-приложение (Frontend)
├── cinema-server/       # PHP API (Backend)
│   └── api/             # Эндпоинты (add_film.php, buy_ticket.php и т.д.)
└── DataBase/            # Скрипты инициализации БД
    ├── db.php           # Подключение к SQLite через PDO
    ├── init_db.php      # Создание таблиц
    ├── seed.php         # Заполнение тестовыми данными
    └── cinema.sqlite    # Файл базы данных (создается при выполнении скрипта init_db.php)
